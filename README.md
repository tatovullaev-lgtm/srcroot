#srcroot

## Framework
The srcroot software for the SRC experiment based on bmnroot (Pavel Batyuk, Konstantin Gertsenberger, Sergey Merts and Oleg Rogachevsky, The BmnRoot framework for experimental data processing in the BM@N experiment at NICA,[EPJ Web Conf., 214 (2019) 05027]) at the NICA facilty (JINR, Dubna) is based on the [ROOT](https://root.cern.ch) environment and object-oriented framework [FairRoot](https://github.com/FairRootGroup/FairRoot) and provides a tools for SRC studies, development of algorithms for simulation, reconstruction and physics analysis of the data.
